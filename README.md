Simple Calculator Using C++

Project Overview

The Simple Calculator is a console-based application developed using C++. It performs basic arithmetic operations based on the user's choice.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Input validation
- Option to perform multiple calculations
- Clear menu and result display

Technologies Used

- Programming Language: C++
- Compiler: GCC (g++)
- Code Editor: Visual Studio Code

How to Run

Step 1: Compile the Program

Open the terminal in the project folder and run:

g++ calculator.cpp -o calculator.exe

Step 2: Execute the Program

On Windows, run:

.\calculator.exe

Learning Outcomes

This project demonstrates the use of variables, arithmetic operators, conditional statements, loops, input validation, and basic error handling in C++.
